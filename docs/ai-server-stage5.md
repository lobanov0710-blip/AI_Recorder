# Этап 5: подключение локального AI-сервера

Debug-сборка отправляет сохранённую M4A-запись в `POST http://10.0.2.2:8000/v1/analyze`.
Для этого этапа Android Emulator и сервер должны работать на одном ПК.
Адрес `10.0.2.2` в эмуляторе соответствует localhost компьютера.
FastAPI остаётся привязан к `127.0.0.1:8000`, Ollama — к `127.0.0.1:11434`.

## Контракт

Multipart-поля: положительный `record_id` и `file` с типом `audio/mp4`.
Ответ: `recordId`, `transcript`, `summary`, `suggestedTitle`, `tasks` (массив строк).
Все пять полей обязательны. Другой `recordId`, повторяющиеся или неизвестные поля,
неверные типы, повреждённый UTF-8, неполный JSON и лишние данные после JSON отклоняются.

`RemoteAiProcessor` выполняется существующим `AiProcessingWorker`; результат попадает
в Room и отображается существующим экраном AI-анализа. Название записи не меняется
автоматически. Схема Room и тракт записи звука остаются прежними.

## Ограничения и ошибки

- Файл: не более 20 МиБ. Ответ API: не более 128 КиБ после распаковки.
- Полный HTTP-запрос: до 8 минут; соединение: до 10 секунд; запись данных: до 60 секунд.
- Перенаправления, прокси системы и повторы на уровне HTTP-клиента отключены.
  Временные ошибки передаются WorkManager, где уже действует ограничение трёх попыток.
- `429`, отсутствие соединения, тайм-аут и временная недоступность сервера допускают повтор.
  Неверный ответ, чужой ID, ограничения записи и отсутствующая модель — постоянные ошибки.
- `cancel()` закрывает активный HTTP-вызов. Уже начатый расчёт Whisper/Ollama на сервере
  может завершаться после отмены клиента; серверного API отмены в этом прототипе нет.
- Защита существующей очереди не позволяет отменённой или удалённой записи сохранить
  поздний результат. Кнопка отмены не удаляет ранее сохранённый анализ.
- Сервер 0.3.1 дополнительно ограничивает аудио пятью минутами, а анализ — 4096 байтами
  текста UTF-8. Для первой проверки используйте короткую запись из двух предложений.

## Конфигурация сборок

`AI_SERVER_BASE_URL` задаётся в `app/build.gradle.kts`: debug — `http://10.0.2.2:8000/`,
release — пустая строка. Пустая или неверная конфигурация возвращает `AI_NOT_CONFIGURED`.
Debug-конфигурация явно разрешает HTTP для `10.0.2.2`; для внешних доменов и других
не-loopback IP-адресов сохраняется запрет HTTP. Начиная с Android 17 (API 37), ОС также
неявно разрешает HTTP для localhost и loopback-адресов, включая `127.0.0.1`, если для
них не задано отдельное правило. Приложение не переопределяет это системное исключение.
Инструментальный тест учитывает его по версии Android и проверяет, что внешние адреса
остаются запрещены. См. раздел Localhost configuration в
[документации Android](https://developer.android.com/privacy-and-security/security-config).
В release локальный сервер не включён. Доступ с физического телефона, HTTPS и
аутентификация требуют отдельной настройки; этот этап проверяет соединение в эмуляторе.

Добавлены OkHttp 4.12.0, Gson 2.14.0 (потоковый разбор без отражения) и test-only
MockWebServer 4.12.0. Для release будущий адрес должен использовать HTTPS;
проверка сертификатов в HTTP-клиенте стандартная, отключений TLS-проверок нет.

## Проверка в Windows

1. Оставьте Ollama запущенной. В папке `AIRecorderServer` запустите установленный сервер:

   ```powershell
   .\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --workers 1
   ```

2. В терминале Android Studio, в корне Android-репозитория, переключитесь на ветку:

   ```powershell
   git fetch origin
   git switch feature/ai-agent-stage5
   git pull --ff-only
   ```

3. Запустите эмулятор. В его браузере откройте `http://10.0.2.2:8000/health`.
   Ожидается `{"status":"ok"}`.

4. Выполните проверки приложения:

   ```powershell
   .\gradlew.bat :app:testDebugUnitTest :app:connectedDebugAndroidTest
   ```

   JVM-тесты используют только локальный MockWebServer и не требуют AI-моделей.
   Инструментальные тесты проверяют Room/очередь/UI и debug-конфигурацию,
   не отправляя тестовое аудио в настоящий AI-сервер.

5. Соберите и запустите debug-приложение в эмуляторе. Запишите:
   «Завтра в 10 утра позвонить Андрею. До пятницы подготовить список функций приложения».
   Откройте сохранённую запись → AI → «Начать анализ».
   Проверьте текст, обе задачи со сроками и сохранение результата после закрытия экрана.
   Во время следующего запроса проверьте отмену и повтор. При повторе сервер может
   временно отвечать, что занят завершением предыдущего расчёта.

Успех тестов HTTP-клиента не подтверждает реальный запуск Android → Whisper → Qwen:
последний пункт нужно выполнить на ПК с установленными моделями.
